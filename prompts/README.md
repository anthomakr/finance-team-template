# Prompts

Reviewed prompts the team reuses. One file per prompt: `prompts/<short-name>.md`.

Each file holds:

- **Use when**: one sentence.
- **Prompt**: the text, with `<placeholders>` for anything company-specific.
- **Tested on**: the month and entity it was checked against (no figures).

A prompt that you use every month at every entity is a skill waiting to happen: move it to `skills/`.
